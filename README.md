# KirNovEngine
### Движок для создания Консольных RPG игр на C
## Описание(Ru)
Движок написанный на C, с версии 1.1-release поддерживает написание игр на луа, он:
Кросплатформенный
Использует C11
## Установка
Скачайте из релизов плеер KirNovEnginePlayer, напишите код и просто переместите его на файл или пропишите в консоль
```bash
./KirnovEnginePlayer.exe твойфайл.lua
```
## Как писать-то на нем?
посмотрите папку [docs](https://github.com/Kirillovo-Company/KirNovEngine/tree/main/docs) там лежит документация по движку
# KirNovEngine
A C-based engine for creating Console RPG games
## Description (En)

A game engine written in C. Starting from version 1.1-release, it supports game scripting via Lua. Key features:
Cross-platform
Uses C11 standard
## Installation

Download the KirNovEnginePlayer from the releases page. To run your game, simply drag and drop your script onto the executable or use the terminal:
Bash
```bash
./KirnovEnginePlayer.exe your_file.lua
```

Check the [docs](https://github.com/Kirillovo-Company/KirNovEngine/tree/main/docs) folder for the full engine documentation and API references.
