# KirNovEngine
### InWork Branch of KirNovEngine
## Описание(Ru)
Движок написанный на C, он:
Кросплатформенный
Использует C11
## Установка
Скачайте саму библиотеку с гитхаба, откройте ваш проект, киньте в папку с вашим .c файлом библиотеку и инициализируйте ее
```c
#include "KirNovEngine.h"

int main() {
    keng_init("My Game");
    return 0;
}
```
