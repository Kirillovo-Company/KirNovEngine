
KirNovEngine v1.0 - Документация (RU)
Разработчик: Kirillovo Company

ОПИСАНИЕ
Легковесный кроссплатформенный движок на языке C99 для создания текстовых RPG 
и консольных квестов. Поддерживает Arch Linux и Windows (MinGW/CLion).

БЫСТРЫЙ СТАРТ
Для начала работы подключите заголовочный файл в ваш проект:
#include "KirNovEngine.h"

ОСНОВНЫЕ ФУНКЦИИ
1. keng_init(str gamename)
   Инициализация движка: устанавливает кодировку UTF-8 (для Windows) 
   и задает заголовок окна консоли.
   Пример: keng_init("Dark Dungeon");

2. gamelog(str log, str color)
   Выводит сообщение с префиксом [LOG] и указанным цветом.
   Пример: gamelog("Вы вошли в пещеру", C_YELLOW);

3. menu(str title, Button* buttons, i32 count)
   Создает интерактивное меню. Ожидает ввода цифры от пользователя.
   Возвращает actionID выбранной кнопки.
   Пример:
   Button b[] = { {"Влево", 1}, {"Вправо", 2} };
   i32 act = menu("ВЫБОР ПУТИ", b, 2);

ЦВЕТОВЫЕ МАКРОСЫ
Используются в функции gamelog:
- C_RED: Красный (Урон, опасности)
- C_GREEN: Зеленый (Успех, лечение)
- C_YELLOW: Желтый (Описания, квесты)
- C_BLUE: Синий (Системная информация)
- C_RESET: Сброс цвета (Стандартный текст)

ТИПЫ ДАННЫХ
- str: Псевдоним для char* (строки)
- i32: Псевдоним для int (32-битные целые числа)
- Button: Структура для кнопок (label, actionID)
