==================================================
        KirNovEngine v1.1 - Documentation
==================================================

KirNovEngine is a lightweight console engine for creating 
text adventures and visual novels using the Lua language.

--- CORE FUNCTIONS (API) ---

1. say(name, name_color, text, text_color, speed)
   Displays a character's dialogue with a typewriter effect.
   Example: say("Nikita", C_CYAN, "Hello world!", C_RESET, 50)

2. dialogue(text, color, speed)
   Displays narrative text or thoughts without a character name.
   Example: dialogue("Thunder roared in the sky...", C_YELLOW, 60)

3. menu(title, options_list)
   Creates an interactive menu. Returns the ID of the choice (1, 2, 3...).
   Example: local choice = menu("Where to go?", {"Forest", "City"})

4. input(prompt)
   Asks the player to type text. Returns the entered string.
   Example: local name = input("Enter your name: ")

--- COLOR CONSTANTS ---
Use these to color your text:
C_RED, C_GREEN, C_YELLOW, C_BLUE, C_MAGENTA, C_CYAN, C_RESET

--- HOW TO UPDATE THE GAME ---
To change the story, simply edit the 'main.lua' file. 
Recompiling the engine (KirNovEngine.exe) is not required 
unless you change its internal C code.
